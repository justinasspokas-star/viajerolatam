ViajeroLatam — Intermundial page-level tracking

What was changed:
- All Intermundial affiliate links now keep the original affiliate URL and original utm_term/utm_content values.
- Added extra parameters to every Intermundial link:
  vl_site=viajerolatam
  vl_partner=intermundial
  vl_page=<page_slug>
  vl_link=<number_on_that_page>
- Added data attributes on Intermundial anchors:
  data-affiliate-partner="intermundial"
  data-vl-page="<page_slug>"

Important:
- This will not break the original affiliate link because the original affiliate parameters are preserved.
- It should help if Intermundial records full landing URLs or custom parameters.
- It is NOT guaranteed that Intermundial will show these custom parameters in the transaction list.
- If custom parameters are not visible, ask Intermundial which exact subID/channel parameter they support.

Files:
- INTERMUNDIAL_PAGE_TRACKING_LINKS.csv contains all page-specific links.

How to verify:
1. Upload the full ZIP.
2. Open one page, for example /seguro-viaje/colombia-a-espana/.
3. Hover/copy the Intermundial button.
4. Confirm the URL includes:
   vl_page=seguro_viaje_colombia_a_espana
5. When a new sale appears, export CSV and check if vl_page / channel / note appears.
6. If not, use the support message below.
